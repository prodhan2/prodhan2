I'm **Sujan Prodhan**, a Computer Science and Engineering student at the University of Rajshahi, passionate about database systems, software architecture, and building practical digital products.

My development approach combines reliable data management with intuitive application design. I enjoy working with structured and unstructured data, designing efficient database schemas, connecting applications to cloud backends, and building software that solves real-world problems.

### What defines my work

- 🗄️ **Database Engineering:** Data modeling, schema design, SQL/NoSQL concepts, and data integrity.
- ⚡ **Query & Performance:** Efficient data access, indexing concepts, and performance-conscious application design.
- 🔥 **Cloud Data Systems:** Firebase, Cloud Firestore, authentication, synchronization, and application data.
- 📱 **Application Engineering:** Flutter, Dart, API integration, and cross-platform development.
- 🌍 **Real-World Projects:** Community platforms and digital services through projects such as RU Connect and Beautiful Dinajpur.

> **My philosophy:** Great software starts with well-designed data and grows through thoughtful engineering.
